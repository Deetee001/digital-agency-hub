## Overview
A full-service digital agency based in Oberlin, OH serving local businesses, growing companies, and nonprofits across NE Ohio. Founded by a Business Intelligence Analyst.

**Four core service lines:**
1. **Web Design** — Websites for businesses with no online presence or outdated sites
2. **Business Intelligence & Analytics** — Dashboards, revenue insights, KPI reporting
3. **Cloud Data Infrastructure** — Set up databases, migrate from spreadsheets, build data pipelines
4. **Process Automation** — Automate repetitive workflows using Zapier, Python, or custom scripts

---

## Project Structure

```
/leads/          — Prospect lists (web clients + BI/analytics clients), CRM tracker
/outreach/       — Email, SMS, and call templates for all service lines
/clients/        — Active client folders (one per client)
/portfolio/      — Completed work screenshots and case studies
/plans/          — Business plan, pricing, naming/branding, outreach strategy
/tools/          — Setup guides for Gmail, Twilio, and automation tools
/scripts/        — Automation scripts (text sender, bulk outreach, etc.)
```

## Tools Setup
- **Email**: Gmail MCP (already available — just authenticate)
- **SMS**: Twilio → `tools/twilio_setup.md` + `scripts/send_text.py`
- **Website Builder**: HTML/CSS or WordPress
- **BI Tools**: Power BI, Looker Studio, Python/pandas
- **Cloud DB**: AWS, Google BigQuery, Supabase
- **Automation**: Zapier, Make, n8n, Python
- **CRM**: `leads/crm_tracker.md` (upgrade to HubSpot Free when volume grows)
- **Domain/Hosting**: Namecheap + Netlify/Vercel
