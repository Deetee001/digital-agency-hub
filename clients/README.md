# Clients

One folder per active/completed client.

## Folder Structure Per Client

```
/clients/[business-name]/
  contract.md          — Agreed scope, price, and payment terms
  discovery.md         — Answers to discovery questions
  assets/              — Logos, photos, copy provided by client
  mockup/              — Figma or HTML mockup files
  live_url.txt         — Final website URL after launch
  invoice.md           — Payment status
```

## How to Create a New Client Folder

When a business signs on:
1. Create folder: `/clients/[business-name]/`
2. Copy `templates/client_template/` into it
3. Fill in contract.md with agreed terms
4. Send invoice for 50% deposit before starting work

## Invoice Template

```
# Invoice — [Business Name]

Date: [DATE]
Project: Website Design & Development
Package: [Starter / Standard / Premium]

Subtotal: $[PRICE]
Deposit Due (50%): $[PRICE/2]
Balance Due on Launch: $[PRICE/2]

Payment methods accepted:
- Venmo: @[your-venmo]
- Zelle: [your-phone]
- Cash / Check
```
