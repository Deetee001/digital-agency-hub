# Portfolio

This folder stores completed website screenshots, mockups, and case studies.

## Structure

```
/portfolio
  /sample-restaurant/      — Demo restaurant site (for pitching)
  /sample-auto-shop/       — Demo auto repair site (for pitching)
  /[client-name]/          — Screenshots + case study after launch
```

## What to Include Per Client

After launching each site, save:
- `before.png` — screenshot of their old site (or note "no website before")
- `after.png` — screenshot of the live new site
- `case_study.md` — 2–3 sentences: what they had, what you built, outcome

## Why This Matters
When pitching new clients, you can say:
> "Here's a restaurant just like yours that I built a site for — 
>  they went from no online presence to showing up #3 on Google Maps."
